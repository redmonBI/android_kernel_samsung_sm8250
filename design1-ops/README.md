# LUMEN · 디자인1팀 업무운영

조명 설계 1팀의 요청, 수행, 협업, 종료를 주 단위로 닫는 운영 장부입니다. 2026년 4월부터 10월까지 쌓인 주간 체크리스트 26장을 하나의 원장으로 옮겼습니다.

## 실행

이 주소는 저장소 페이지가 아닙니다. `design1-ops`에서 서버를 켠 뒤 브라우저로 열어야 합니다.

```bash
cd design1-ops
node server.js
```

같은 컴퓨터에서는 http://127.0.0.1:4173 입니다. 로그인 화면에 “서버에 연결되었습니다”가 보여야 합니다. 같은 사무실 네트워크의 다른 컴퓨터는 서버를 켠 컴퓨터의 IP에 4173 포트를 붙여 접속합니다.

팀원 PC가 꺼져도 접속되게 하려면 이 서버를 항상 켜 둘 사내 PC나 호스팅에 두면 됩니다. 데이터는 `data/state.json` 한 파일이며, 이 파일을 복사하면 백업이 됩니다.

조직 화면에서 비밀번호를 바꾸고 계정을 추가할 수 있습니다.

## 운영 흐름

1. **생각** — 부서, 요청자, 종료 예정, 작업 유형을 적어 접수합니다.
2. **행동** — 담당이 진도와 이번 주 진행을 남깁니다.
3. **연결** — 재작업, 보류, 타부서 회신을 상태와 기록으로 추적합니다.
4. **종료** — 산출물 한 줄이 있어야 완료가 됩니다.

같은 진도가 4주 이상 이어지면 정체로 올라옵니다. 팀장은 계획, 중간 점검, 주간 마감을 체크하고, 끝나지 않은 일만 다음 주 보드로 이월합니다.

보고의 슬롯 완료율은 기존 시트처럼 그 기간 보드에 올라온 줄 기준입니다. 고유 업무 수는 여러 주에 반복된 일을 한 건으로 모은 값입니다.
