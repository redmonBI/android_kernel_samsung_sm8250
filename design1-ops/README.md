# LUMEN · 디자인1팀 업무 데스크

구글 시트의 주간 업무 체크 리스트를 읽고, 팀장이 놓친 일·겹친 일·사람별 업무량을 한 화면에서 보게 하는 데스크입니다. 시트 밖에 적어 두는 개인 할 일도 같은 알림 기준으로 챙깁니다.

시트 원본: [2026_업무 관리](https://docs.google.com/spreadsheets/d/1P7_T0UkuCXl9USkvgvLR52Ft7OMgl7OMSZe5e6TRuu0/edit?gid=514547906#gid=514547906)

## 실행

```bash
cd design1-ops
node server.js
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 서버가 최신 `업무 체크 리스트` 탭을 약 45초마다 다시 읽습니다.

| 계정 | 아이디 | 비밀번호 | 할 수 있는 일 |
| --- | --- | --- | --- |
| 팀장 JH | `jh` | `lumen-lead` | 시트 탭, 알림 기준, 팀 분장 |
| 선임 DE | `de` | `lumen-de` | 체크, 본인 할 일 |
| 사원 GY | `gy` | `lumen-gy` | 체크, 본인 할 일 |

기록은 `data/state.json`에 남습니다. 이 파일을 복사하면 백업이 됩니다.

## 시트와 데스크가 나누는 일

시트는 팀 원본입니다. 추가와 수정은 시트에서 하고, 데스크는 달라진 줄을 알립니다. 처음 연결할 때는 이미 있는 줄을 전부 신규로 띄우지 않고, 그 다음 새로고침부터 추가·수정·삭제만 알립니다. 수정 시각만 바뀐 경우는 한 줄로 묶습니다.

체크에서 고를 수 있는 것은 세 가지입니다.

- **완료** — 데스크에 완료로 남깁니다. 시트 상태가 아직 진행중이면 `데스크 완료`로 표시하니, 시트도 완료로 고칩니다.
- **재확인** — 1시간 뒤, 또는 내일 아침 9시에 다시 띄웁니다.
- **일정 변경** — 데스크의 종료 시각을 바꿉니다. 시트 날짜와 다르면 배지로 남습니다.

종료칸에 날짜만 있으면 기본 18:00으로 봅니다. 하루 전(24시간)과 한 시간 전(60분)은 알림 화면에서 팀장이 바꿀 수 있습니다.

팝업으로 막아서 확인시키는 경우는 다음과 같습니다.

- 종료 한 시간 전
- 중요로 표시한 업무와 할 일
- 긴급이면서 하루 전·기한 지남
- 높음이면서 36시간 안에 기한이 지난 업무
- 긴급 업무의 추가·수정·삭제, 새 주간 시트

팝업은 완료, 재확인, 일정 변경 중 하나를 고르기 전에는 닫히지 않습니다. `한 시간 뒤에 다시 보기`는 지금 떠 있는 확인을 한 시간 미룹니다.

## 팀장이 보는 것

- **오늘** — 체크할 시트 업무, 내 할 일, 내 담당, 방금 바뀐 줄
- **이번 주 시트** — 상태·우선순위·담당·기한 필터와 상세
- **팀 분장** — 사람별 열린 업무, 긴급 개수, 같은 프로젝트 이름이 두 줄 이상인 경우
- **내 할 일** — 시트에 없는 일을 오늘 / 이번 주 / 다음 주 / 나중으로 옮김
- **알림** — 변경 내역과 기한 기준

개인 할 일은 계정마다 따로 저장됩니다. 날짜가 오늘이거나 지난 일은 어느 칸에 두었든 오늘로 올라옵니다. 다음 주로 넘기면 날짜도 다음 주로 이동합니다.

참고한 운영 방식은 Asana의 내 할 일과 기한 알림, monday.com의 담당별 부하, ClickUp의 우선순위와 리마인더, Todoist의 오늘/다음 주 이동입니다. 시간 기록이나 간트처럼 이 팀 시트에 없는 기능은 넣지 않았습니다.
