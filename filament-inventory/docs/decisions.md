# 결정

## 고도몰 안에 넣지 않음

예약 동시성, 역할별 원가, 제안서 편집, 엑셀 승인 전 비교는 고도몰 스킨 HTML로 안전하게 만들기 어렵다. 별도 앱으로 두고 공개 카탈로그만 같은 브랜드로 다시 구성했다.

## SQLite

이 실행 환경에 Docker가 없어 PostgreSQL 대신 SQLite를 기본으로 했다. 금액은 정수, 승인은 `BEGIN IMMEDIATE`로 잠근다. `docker-compose.yml`의 Postgres는 이후 이전용이다.

## 예시 재고

실제 엑셀이 없어 공개 사이트의 제품 사진과 품목코드만 가져왔다. 수량, 원가, 판매가, 등급, 우선순위는 예시이고 `is_sample = 1`이다. 엑셀 승인이나 재고 조정 승인이 되면 해당 품목의 예시 표시를 끈다.

## 제안서 PDF

한글은 브라우저 인쇄가 안정적이다. 서버에서 별도 PDF 엔진으로 그리면 글꼴을 다시 넣어야 해서, 편집 화면과 인쇄 화면을 두고 사용자가 PDF로 저장하게 했다.

## 저장소 위치

요청이 이 작업 공간에서 진행되어 앱은 `filament-inventory/`에만 있다. 커널 소스는 수정하지 않았다. 재고 원장이 공개 저장소에 올라가지 않도록 DB와 업로드 파일은 Git에서 제외했다.
