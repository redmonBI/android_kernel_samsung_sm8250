# 엑셀 반영 규칙

기준 시트 이름은 공백을 뺀 `전체목록`이다. 없으면 첫 시트를 읽는다.

읽는 열: 품목코드, 품명, 품목구분, 등급, 재고구분, 규격, 적용 W, 색온도및 연색성, 각도, 사이즈, 제조사, 재고, 단가, 금액, 관련 부서, 소진 방안 및 일정 계획, 품목 이력, 처리구분.

금액이 있고 `재고 × 단가`와 다르면 오류다. 표시된 합계 수식은 믿지 않는다. 품목코드 중복, 품명 없음, 수량·단가 누락도 오류다.

전체 동기화:

- 파일에만 있음: 추가
- 값이 다름: 변경
- 같음: 변경 없음
- DB에만 있음: 삭제 후보. 바로 지우지 않음

변경분 파일의 처리구분: `ADD`, `UPDATE`, `UPSERT`, `DELETE`. `DELETE`는 삭제 요청만 만든다.

승인 전에는 `products`와 `inventory_items`를 바꾸지 않는다. 승인 시 추가·변경만 반영하고, 삭제 후보는 `delete_requests`에 `candidate`로 남긴다. 소프트 삭제는 상세 화면에서 따로 한다.

엑셀이 덮지 않는 값: 판매가, 사진, 하자, 예약, 출고, 프로모션, 선택 목록, 제안서, 댓글, 감사 로그.

새 품목의 판매가는 일단 단가와 같게 시작하고, 영업 화면에서 고친다. 빈 부서·빈 소진 계획은 기존 값을 비우지 않는다.

`xlsm`과 `vbaProject`가 들어 있는 파일은 거부한다. 템플릿은 `public/templates/full-sync.xlsx`, `public/templates/delta.xlsx`.

되돌리기는 가장 최근 승인 건만 가능하고, 추가 품목에 승인된 예약이 있으면 멈춘다. 사진과 판매가는 되돌리기에도 유지된다.
