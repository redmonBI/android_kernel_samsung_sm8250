# 구현 계획과 현재 상태

1. 공개 카탈로그와 사내 재고가 한 Next.js 앱에서 동작한다.
2. 예시 데이터로 로그인, 목록, 상세, 선택, 제안서, 엑셀 비교가 열린다.
3. 도메인 테스트가 재고 식, 원가 차단, 엑셀 반영, 예약 초과, 삭제 복구를 통과한다.

남은 운영 작업:

- 실제 엑셀을 업데이트 센터에 올려 승인자 계정으로 반영한다. 파일은 Git에 넣지 않는다.
- 예시 배너가 사라지는지 확인한다. `is_sample`이 0이 된 품목만 실제 재고로 본다.
- 비밀번호와 `SESSION_SECRET`을 바꾼다.
- 사양이 비어 있는 품목은 상세의 운영 정보에서 W, 색온도, 각도를 채운다.
- 고도몰 도메인을 이 앱으로 옮길지는 별도 결정이다. 옮기기 전에는 공개 사이트로 이 앱을 병행할 수 있다.

PostgreSQL용 `docker-compose.yml`은 준비만 되어 있다. 실행 기본값은 SQLite다.
