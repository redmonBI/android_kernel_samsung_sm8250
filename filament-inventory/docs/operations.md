# 운영

로컬 실행은 `npm run dev`다. 데이터는 `data/app.db`, 업로드 원본은 `data/uploads`다. 둘 다 Git에 올리지 않는다.

처음 실행하면 예시 계정과 예시 재고가 만들어진다. 상단 노란 줄이 보이면 아직 예시 단가다.

실제 반영 순서:

1. 구매지원 또는 관리자가 업데이트 센터에서 전체 파일을 올린다.
2. 추가, 변경, 삭제 후보, 오류를 본다. 오류가 있으면 파일을 고친다.
3. 승인자 또는 관리자가 승인한다. 그 전에 수량은 바뀌지 않는다.
4. 판매가와 사양, 담당, 우선순위를 제품 상세에서 고친다.
5. 예시 줄이 사라졌는지 확인한 뒤 제안서를 만든다.

비밀번호는 코드에 평문으로 저장하지 않고 scrypt 해시로 둔다. 세션 쿠키는 `httpOnly`다. 공개 배포에서는 HTTPS와 새 `SESSION_SECRET`이 필요하다.

회사 정보로 화면에 넣은 값은 공개 사이트 하단의 주소와 전화, 메일 `yjel1040@naver.com`뿐이다. 사업자등록번호는 확인된 값이 없어 만들지 않았다.
