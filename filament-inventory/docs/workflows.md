# 업무 흐름

## 제품을 제안서로

1. 제품·재고에서 담기를 누른다.
2. 선택 목록에서 수량, 고객, 프로젝트, 필요일을 저장한다.
3. 제안서 만들기 후 문구와 단가를 고친다.
4. 미리보기에서 인쇄하고 PDF로 저장한다.
5. 상태가 `전달함`이면 보낸 제안으로 표시한다. 복제하면 초안이 하나 더 생긴다.

## 예약

예약 요청은 가용수량을 바로 줄이지 않는다. 승인자가 업무함에서 승인하면 그 시점의 가용수량을 다시 계산해 예약 수량을 더한다. 넘치면 승인되지 않는다.

## 수량과 원가

일반 저장 폼으로는 ERP 수량과 구매원가를 바꾸지 않는다. 조정 요청에 사유를 적고, 승인 후 반영한다. 판매가는 영업·구매·관리자가 바로 고칠 수 있고 이력에 남는다.

## 출고 예정

물류·구매·관리자가 수량을 요청한다. 승인되면 출고 예정 수량에 더하고 가용수량에서 빠진다.

## 삭제

엑셀에 없는 품목은 삭제 후보만 생긴다. 소프트 삭제는 `deleted_at`을 채우고, 복구하면 비운다. 승인된 예약이 있으면 삭제하지 않는다.

## 콘텐츠

관리자와 영업, 부서 담당은 배너와 게시글을 등록한다. 공개 문의는 `posts.board = inquiry`이고 공개 목록에는 나오지 않는다.
