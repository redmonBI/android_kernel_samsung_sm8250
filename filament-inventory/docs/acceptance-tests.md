# 인수 확인

자동 테스트 `npm test`:

- 가용수량 식과 금액 정수 계산
- 대시보드 총액과 목록 합계 일치
- 영업·공개 응답에 구매원가 없음, 재무 응답에는 있음
- 금액 불일치를 오류로 구분, 파일에 없는 기존 품목은 삭제 후보
- 승인 전 수량 불변, 승인 후 판매가와 사진 유지
- 매크로 파일 거부
- 가용 5에서 4씩 두 번 승인하면 두 번째는 실패하고 남은 수량은 1
- 다른 DB 연결이 잠그면 승인이 진행되지 않음
- 소프트 삭제와 복구가 감사 로그에 남음
- ERP CSV의 품목코드·수량 일치

수동으로 확인한 화면:

- 공개 홈, 제품 목록, 제품 상세 200. 상세에 구매원가 없음
- 로그인 없이 `/app`은 로그인으로 이동
- 영업 세션의 `/api/products`에 `unitCost` 없음
- 관리자 세션에는 `unitCost` 있음
- 사내 목록에 가용수량·등급·필터, 업데이트 센터, 선택 목록, 배너 관리 표시

1280px 고정 폭 1800px는 마크업에 없다. 브라우저 인쇄로 PDF를 저장하는 동작은 인쇄 대화상자가 필요해 자동 테스트에 넣지 않았다.
