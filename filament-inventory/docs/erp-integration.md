# ERP 연결

실시간 ERP 인터페이스는 아직 없다. 재고의 기준 수량은 엑셀의 `재고`와 `단가`를 승인한 값이다.

선택 목록은 품목코드와 수량만 CSV 또는 XLSX로 내려받는다. 화면의 코드·수량과 파일 내용이 같다. 구매원가와 판매가는 이 파일에 넣지 않는다.

엑셀을 다시 올려도 사이트의 판매가, 사진, 하자, 예약, 제안서는 유지한다. ERP 수량과 구매원가만 비교 결과에 따라 바뀐다.

예약은 ERP 실재고를 즉시 바꾸지 않는 소프트 예약이다. ERP에 출고를 입력한 뒤에는 변경분 엑셀이나 재고 조정으로 현재수량을 맞춘다.
